# ONE × HPL Schools — prezentare locală

Deschideți `index.html` în browser. Pentru GitHub Pages încărcați conținutul acestui dosar în rădăcina repository-ului și activați Pages pentru ramura dorită. Nu necesită instalare sau server.

Pagina este un material de prezentare, nu un site oficial ONE. Siglele sunt reprezentate tipografic; utilizarea mărcilor și a materialelor oficiale trebuie agreată cu titularii. Fonturile Google sunt opționale: pagina funcționează și offline cu fonturi de rezervă.
